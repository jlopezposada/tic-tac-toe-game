# Tic-Tac-Toe Game

A simple console-based Tic-Tac-Toe game written in C++. Players enter their names, take turns choosing a row and column, and the game detects a winner when a player completes a row, column, or diagonal.

## Features
- Two-player gameplay
- Randomly decides who starts
- Input validation for moves
- Win detection for rows, columns, and diagonals

## How to Run
Compile the program with:

```bash
g++ ttt.cpp ttt_functions.cpp -o ttt.exe
```

Then run it with:

```bash
./ttt.exe
```

## Project Files
- ttt.cpp - main program entry point
- ttt.hpp - function declarations
- ttt_functions.cpp - game logic and board functions
